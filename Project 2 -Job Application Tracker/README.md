# 🧾 Job Application Tracker

A web-based application that helps users track and manage their job applications efficiently. This project allows users to store job details, update application statuses, and view application statistics through a simple dashboard.

---

## 🚀 Features

- 🔐 User Registration and Login System  
- ➕ Add, ✏️ Edit, and ❌ Delete Job Applications  
- 📌 Track Application Status (Applied, Interview, Selected, Rejected)  
- 📊 Dashboard with job application statistics  
- 🗂 Organized database storage using MySQL  

---

## 🛠 Technologies Used

- **Frontend:** HTML, CSS, JavaScript  
- **Backend:** PHP  
- **Database:** MySQL  
- **Server Environment:** XAMPP / Localhost  

---

## ⚙️ How to Run This Project Locally

1. Install **XAMPP** (or any local PHP server)
2. Copy the project folder into the `htdocs` directory  
   Example:  
   `C:\xampp\htdocs\job-application-tracker`
3. Start **Apache** and **MySQL** from XAMPP Control Panel
4. Open **phpMyAdmin**
5. Create a new database (e.g., `job_tracker`)
6. Import the provided SQL file into the database
7. Open your browser and go to:
      localhost:/job-application-tracker

## 📂 Project Modules

- **Authentication System** – Secure login and registration  
- **Job Management** – Store company name, role, date applied, and status  
- **Dashboard** – View total applications and status breakdown
